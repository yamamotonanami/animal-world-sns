# Zootalk プレゼンテーション資料（骨子）

## 1. イントロダクション & コンセプト (Inspiration & Concept)

### タイトル
**Zootalk - 動物たちの世界へようこそ**
サブタイトル: 「もしも動物の世界にSNSがあったら？」を実現するAI SNS

### 着想の原点 (Start with Fun)
*   **「もしも『ズートピア』のような世界にSNSがあったら？」**
    *   多様な動物たちが、種族の違いを超えて共存し、何気ない日常を呟き合う。
    *   そんなワクワクする世界（Animal World）を作りたいという好奇心がスタート地点。

### ターゲットユーザーと提供価値 (Stay for Heal)
*   **ターゲット:**
    *   既存のSNSで「個」としての振る舞いや、他者からの評価（いいね数・フォロワー数）に疲れを感じている層。
    *   社会的役割（上司、親、友人など）の板挟みになり、本音を吐き出せない人々。
*   **インサイト:**
    *   「人間を辞めたい」「たまには別の何かになりたい」という潜在的な変身願望と逃避欲求。
*   **Zootalkのアンサー:**
    *   ここは「人間禁止」。
    *   ワクワクする世界観の中で、**「動物というロール（役割/アバター）」を被ることで、逆説的に「素の自分（本音）」を解放できる場所**を提供する。
    *   評価経済からの脱却と、心理的安全性の保証。

---

## 2. プロダクトの強み：AI × 世界観 (Core Value)

### 最大のユニークポイント: Geminiによる「人格」の再構築
*   **機能:**
    *   ユーザーの投稿は、そのままでは世界に放たれない。必ずAI（Google Gemini）による「翻訳」プロセスを経る。
*   **Gemini活用のこだわり:**
    *   単なる語尾変換（「〜だワン」）ではなく、Few-shotプロンプト技術を用いた**「人格・思考プロセスの変換」**。
    *   **直情的なイヌ:** 「仕事疲れた」→「今日の狩りはハードだった！早く群れのみんなと体を寄せ合って眠りたい！」
    *   **気儘なネコ:** 「仕事疲れた」→「もう何もしたくない気分。高い場所から下界を見下ろして、毛づくろいでもして過ごすわ。」
*   **体験価値:**
    *   ネガティブな愚痴や弱音も、動物の言葉や仕草に変換されることで角が取れ、ユーモアのあるエンターテインメントに昇華される。
    *   これにより、**「何を言っても（AIが直してくれるから）許される」という究極の心理的安全性**を実現。

### 世界観設計: Generative AIのフル活用
*   **アセット制作:**
    *   画像生成AI「Nanobanana」とデザインツール「Canva」を駆使。
    *   動物のアイコン、エリア背景（街・森・湖）、UIパーツを一貫したトーン＆マナーで作成。
*   **没入感の演出:**
    *   「街（賑やか）」「森（癒やし）」「湖（静寂）」という3つのバイオーム（エリア）。
    *   エリアを選択することで、背景ビジュアルだけでなく、AI翻訳のコンテキスト（空気感）も変化する設計。

## 3. リテンション & 拡張性 (Retention & Business)

### 継続利用の動機付け: 称号（タイトル）システム
*   **狙い:**
    *   「いいね数」という他人との競争指標を排除した代わりに、継続する楽しみを作る。
*   **仕組み:**
    *   行動履歴に基づき、ユニークな「称号」を付与。（例：「初めての遠吠え」「森の賢者」「湖畔の詩人」）
    *   **承認欲求のベクトル転換:** 「他者からの評価」ではなく、「自分の動物としてのキャリア（生きた証）の収集」へ。

### 拡張性とマネタイズの展望
*   **無限の拡張ロードマップ:**
    *   **エリア拡張:** 「深海」「天空」「サバンナ」「極地」など、新たなバイオームを追加可能。
    *   **動物拡張:** 十二支、絶滅危惧種、空想上の生き物（ドラゴン等）など、アバターの多様化。
*   **マネタイズポイント:**
    *   新エリアへのパスポート（サブスクリプション）。
    *   レアな動物への変身スキン、特殊リアクションエフェクト（足跡アニメーション等）の販売。

## 4. 開発プロセスと品質管理 (Engineering)

### 技術スタック
*   **Frontend:** Next.js 16 (App Router), Turbopack, Tailwind CSS, Framer Motion
*   **Backend:** Supabase (Auth, DB, Realtime), Clerk (Custom Auth UI)
*   **AI:** Google Gemini API

### 徹底したバージョン管理 (Version Control)
*   **運用:**
    *   機能単位・修正単位で細かくバージョン（v0.19.4など）を定義し、Gitでの管理を徹底。
*   **ビジネスメリット:**
    *   **リスクヘッジ:** バグ発生時に即座に安定板へ戻せる安心感。
    *   **開発スピード:** 「常に動く最新版」を維持することで、大胆な新機能（AIモデル変更やデザイン刷新）のトライアンドエラーを高速化した。

---

## 5. まとめ (Conclusion)

### Zootalkの定義
*   「ズートピア的なワクワク」でユーザーを惹きつけ、「AIによる翻訳体験」で心を癒やし、定着させる新しいSNS。
*   最新技術（Next.js 16, Gemini）を、ユーザーの情緒的価値（エモさ）に完全に落とし込んだプロダクト。
