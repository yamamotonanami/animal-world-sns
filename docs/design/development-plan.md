# 開発・リリース計画

## 1. 開発ロードマップ

### フェーズ 1: MVP開発（2ヶ月）
**目標**: 感情が翻訳され、数字のない空間で共存できるコア体験の構築。
- 基盤構築（Next.js + Supabase + Clerk セットアップ）
- 動物診断ロジックと初期4種の動物人格実装
- AI翻訳エンジンの構築（OpenAI API連携）
- 森のタイムラインと3種のリアクション（点灯のみ）
- プロフィール設定（ニックネーム、初期称号）

### フェーズ 2: 成長システムの導入（1ヶ月）
**目標**: ユーザーの継続的な利用を促す「称号解放」の実装。
- 内部実績カウンターの実装
- 称号解放ロジックと通知演出
- 湖のタイムライン（空間切り替え）の追加
- 管理者用プロンプトエディタの構築

### フェーズ 3: マネタイズと拡張（以後）
**目標**: 持続可能な運営とコミュニティの拡大。
- 課金型動物人格の追加（ショップ機能）
- 世界観調和型広告枠の試験導入
- 季節・時間連動UIの強化

## 3. リスク管理

| リスク | 影響度 | 対策 |
| :--- | :--- | :--- |
| **AI翻訳の不適切発言** | 高 | システムプロンプトでの厳格な指示 ＋ NGワードフィルタ。 |
| **AI APIコストの増大** | 中 | gpt-4o-mini 等の軽量モデルの採用と、投稿頻度の制限。 |
| **数字を求めるユーザーの不満** | 低 | 称号システムにより「自分だけの蓄積」という新しい価値へ誘導する。 |
| **世界観の維持（広告）** | 中 | 広告審査ガイドラインを厳格化し、独自UIでのみ表示。 |

## 4. 運用体制（仮）
- **開発/保守**: エンジニア1〜2名（Next.js/Supabase/AI）
- **世界観管理（管理者）**: あなた。管理画面からプロンプトの調整、称号の追加、コラボ広告の選定。
