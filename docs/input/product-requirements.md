# プロダクト要件

## 1. プロダクト概要
### プロダクト形態
モバイル専用ネイティブアプリ

### 対応プラットフォーム
iOS / Android

### 利用環境
日常のふとした隙間時間やリラックスタイム（場所を問わず、一人で静かに過ごしたい時）

## 2. コアバリュー
### このプロダクトの核となる価値
「人間の感情を動物世界の平和な出来事に変え、安全に外在化し、自分らしい振る舞いが『称号』として蓄積される体験」

### Aha Moment
自分の「疲れた」という投稿が、可愛い柴犬の「日陰で休みたくなった」という言葉に変わり、それに対して「そっと近づく」というリアクションをもらった瞬間。また、日々の振る舞いによって「日向ぼっこの達人」といった新しい称号が静かに増えていることに気づいた時。

## 3. 主要機能
### 必須機能（Must Have）
- **動物人格診断**: 初回登録時の診断テスト。
- **動物人格選択**: デフォルト4種（犬、猫、うさぎ、ビーバー）と見た目（柴犬、三毛猫等）の選択。
- **AI翻訳投稿機能**: 入力テキストを動物の言葉に変換して投稿。
- **タイムライン表示**: 白いカード形式の投稿一覧。
- **非言語リアクション**: 「しぐさ（スタンプ）」による反応。
- **プロフィール設定**: ひらがな・カタカナ6文字ニックネーム ＋ 称号選択。
- **称号成長システム**: 投稿場所やリアクションの種類に応じて新しい称号が解放される仕組み。

### 推奨機能（Should Have）
- **タイムライン切替**: 「森」「湖」の空間切り替え。
- **ショップ機能**: 課金動物（ハムスター、ライオン、キリン等）の購入。

### あれば嬉しい機能（Nice to Have）
- **季節・時間連動UI**: 実際の時間帯や季節に合わせて背景や動物の行動が変化。

## 4. 非機能要件
### パフォーマンス
- 投稿からAI翻訳完了までの待ち時間を5秒以内にする（待機中も世界観に合った演出を挟む）。

### セキュリティ
- 原文データの厳重な保護（他者には絶対に公開されない）。
- 投稿者本人のみ、プロフィール画面の投稿履歴から原文を確認できる（トグル切り替え）。

### 倫理的配慮
- AIの変換が、元の感情を不当に歪めたり、不快な表現を生成したりしないようなガードレール設定。
