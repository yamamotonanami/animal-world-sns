# UI/UX方針

## 1. 全体の方向性

### デザインテーマ
「オーガニック・セーフティ・ミニマル」
（自然の温かさと、時間帯を問わない安心感）

### キーワード
- セージグリーン
- 角丸
- 白いカード
- **点灯（数字のない繋がり）**

## 2. ビジュアル

### カラー方針
- **メインカラー**: セージグリーン
- **アクセントカラー**: 柔らかなマスタードイエロー（スタンプ点灯時の「光」の色）
- **背景**: 時間帯に応じてわずかにトーンが変化するオフホワイト（目に優しい設計）

## 3. UX原則

### 重視する体験
1. **数字からの解放**: いいね数やフォロワー数を一切気にせず、ただそこにいることを楽しむ。
2. **静かな手応え**: スタンプが「1つでも押された」ということが、星が一つ灯るような感覚で伝わる。

### 避けたいUX
1. **比較と競争**: 「誰が一番反応をもらっているか」を推測させるあらゆる要素を排除。

## 4. 画面構成（主要要素）

### 投稿カードのデザイン
- 真っ白な角丸カード。
- 下部に「しっぽを振る」「毛づくろい」「のびをする」の3つのアイコンが控えめに配置されている。
- 反応があると、そのアイコンがマスタードイエローでぼんやりと光る。

## 5. インタラクション

### スタンプの「点灯」
- **自分が見る時**: 自分がスタンプを押すと、アイコンがゆっくりと光を灯す。
- **投稿者が自分の投稿を見る時**: 誰かが1回でも押してくれていれば、アイコンが光っている。
- **光り方**: 鋭いフラッシュではなく、呼吸するようにゆっくり明滅、あるいは静かに点灯し続けるような柔らかい表現。

### フィードバック
- 自分がスタンプを押した瞬間、指先にわずかな振動（Haptics）と、小さく「ぷくっ」とした環境音を返す。
