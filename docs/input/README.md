# 動物世界に翻訳されるSNS（仮）

## 概要
人間の言葉をそのまま流通させず、AIによって「動物世界の言葉」に翻訳することで、安心・ユーモア・一体感のあるSNS体験を提供するスマートフォン専用アプリ。

## 解決する課題
- 既存SNSにおける攻撃性・炎上・正論疲れ
- 自分の言葉をそのまま書くことへの心理的ハードル
- 投稿しないユーザー（見る専）が価値を感じにくい構造

## ターゲットユーザー
- 20〜40代女性（特に夜のひとときを静かに過ごしたい層）

## 主要機能
- **AI動物翻訳投稿**: 入力した本音を動物のしぐさや出来事に変換
- **動物人格診断**: 自分にぴったりの動物を診断・選択
- **称号・ニックネームシステム**: 世界観に浸れるプロフィール設定
- **多空間タイムライン**: 「森」や「湖」といった独立した癒やしの空間
- **非言語リアクション**: 評価ではなく動物の「しぐさ」でつながる
