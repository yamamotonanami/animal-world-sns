# MVP範囲

## MVP定義

### 目的
「人間の言葉を動物世界に翻訳することで、心理的安全性が保たれた平和なSNSが成立するか」を検証する。

### 対象ユーザー
夜のSNS疲れを感じている20〜40代女性（まずは少人数のコミュニティから）。

### 成功の定義
- 投稿ユーザーが「攻撃される心配がない」と感じ、継続的に本音を投稿してくれること。
- 通報率が既存SNSに比べて圧倒的に低いこと。

## スコープ

### MVP に含める ✅
| 機能 | 理由 |
|------|------|
| AI翻訳（基本プロンプト） | プロダクトの核となる体験のため |
| 動物診断＋デフォルト4種選択 | 自分自身の投影に必要 |
| タイムライン（森） | 閲覧・交流の基本空間 |
| 称号＋ニックネーム設定 | 最低限の自己表現 |
| しぐさリアクション | 緩い繋がりの検証 |

### MVP に含めない ❌
| 機能 | 理由 | 対応時期 |
|------|------|----------|
| 課金動物の追加 | マネタイズは価値検証の後でも良いため | Phase 2 |
| 湖のタイムライン（多空間） | 空間の分散はユーザーが増えてからで良いため | Phase 2 |
| 企業コラボ広告 | ユーザー定着を最優先するため | Phase 3 |

## タイムライン（目安）
| フェーズ | 期間 | 内容 |
|----------|------|------|
| MVP開発 | 2ヶ月 | 基盤構築、AIプロンプト調整、基本UI |
| βテスト | 1ヶ月 | 特定ユーザーによるクローズドテスト |
| 本リリース | - | 公開、順次機能追加 |
