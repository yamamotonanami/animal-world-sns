## 機能詳細

### しぐさリアクション（3種限定）
**概要：** 投稿に対する「評価」ではなく、動物としての「振る舞い」を送る。
- **しっぽを振る**: 喜びや親愛
- **毛づくろい**: 労わりやケア
- **のびをする**: リラックスや共感

**表示ルール：**
- **数値は一切表示しない**: 1人でも100人でも、表示は「アイコンが光っている」という状態のみ。
- **投稿者側の見え方**: 自分の投稿カードにある3つのアイコンのうち、誰かが押したものだけが「ぽわんと光る」。誰が押したか、何回押されたかは一切わからない。
- **閲覧者側の見え方**: 自分が押したスタンプが光る。他人が押しているかどうかはわからない。

### 称号成長システム
**概要：** ユーザーのニックネームの前に付与できる二つ名。登録時から選べる「初期称号」と、この世界での過ごし方によって解放される「解放称号」がある。

#### **1. 初期称号（デフォルト）**
- **ふわふわの新参者**
- **ぴかぴかの新入り肉球**
- **震えるしっぽの冒険家**

#### **2. 解放称号（実績・行動型）**
（※条件としてのカウントは内部で保持するが、ユーザーには見せない）
| 称号名 | 解放条件のイメージ |
| :--- | :--- |
| **はじめての足跡** | 森のタイムラインで初めて投稿する |
| **日向ぼっこの達人** | 晴れた日の日中（10〜15時）に累計3回投稿する |
| **真夜中の大運動家** | 深夜（1〜4時）に累計3回投稿する |
| **窓辺の警備隊長** | 「外」「窓」「鳥」などのキーワードを含む投稿をする |
| **換毛期の芸術家** | 「毛づくろい」を累計5回行う |
| **森の番人** | 「森」のタイムラインへの累計投稿数が10回を超える |
| **もふもふの体現者** | 毛の長い動物種で1週間過ごす |
| **湖のほとりで一休み** | 湖のタイムラインに初めて投稿する |
