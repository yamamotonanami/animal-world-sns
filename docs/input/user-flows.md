# ユーザーフロー

## 1. オンボーディングフロー
1. 診断テストを受け、動物種をレコメンドされる。
2. 動物（見た目含む）を決定する。
3. ニックネーム（6文字以内）を入力する。
4. 初期称号（ふわふわの新参者等）を選択する。

## 2. メインフロー
### 感情の投稿
1. 投稿画面で今の気持ちを自由に書く。
2. AI翻訳プレビューで「動物の言葉」を確認して投稿。
3. タイムラインに白いカードが表示される。

### しぐさリアクション
1. タイムラインを眺めていて、共感した投稿のアイコン（3種）をタップする。
2. アイコンが自分の手元で光り、相手に「しぐさ」が届く。

### リアクションの確認（受信側）
1. 自分の過去の投稿を見返す。
2. アイコンが光っていれば、「あ、誰かがこの振る舞いをしてくれたんだな」と気づく。
3. **「いくつ押されたか」は分からないため、一人一人の反応を大切に感じられる。**
4. **「翻訳」ボタン（またはトグル）を押すと、その投稿の原文を確認できる。**

## 3. その他のフロー
### 称号の獲得
1. 内部実績（しぐさの回数など）が達成される。
2. 次にアプリを開いたとき、または画面遷移時に、静かに「新しい称号」の解放が通知される。
3. プロフィール画面で「換毛期の芸術家」などに変更する。
